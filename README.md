# 숫자 야구 (Number Baseball)

React 학습용으로 만드는 숫자 야구 게임입니다.

## 게임 규칙

1. **3자리 / 4자리 / 5자리** 중에서 난이도를 고릅니다. 기본은 3자리입니다.
2. 컴퓨터가 **서로 다른 숫자**로 이루어진 정답을 랜덤으로 만듭니다.
   - 숫자는 0~9, 중복 없음 (`1 2 3` OK / `1 1 2` 불가)
   - 첫 자리에 0이 와도 됩니다 (`0 5 7` OK)
3. 자릿수를 다 채워 입력하면 결과를 알려줍니다.
   - **스트라이크**: 숫자와 자리가 모두 일치한 개수
   - **볼**: 숫자는 정답에 있지만 자리가 다른 개수
   - **아웃**: 정답에 아예 없는 숫자의 개수
   - 예) 정답 `1 2 3`, 입력 `1 3 4` → `1스트라이크 1볼 1아웃`
   - 0개인 것은 적지 않습니다 (`2스트라이크 1볼`)
4. 모든 자리가 스트라이크가 되면 승리입니다 (3자리면 3스트라이크, 5자리면 5스트라이크).
5. 최대 **10번**까지 시도할 수 있고, 다 실패하면 정답을 공개합니다.
   - 시도 횟수는 **난이도와 상관없이 10번**입니다. 자릿수가 많아지면 한 번의 판정에서 얻는 정보도 함께 많아지기 때문입니다.
   - **무제한 기회**를 켜면 맞힐 때까지 끝나지 않습니다. 이때는 오른쪽 위가 `7 / 10` 대신 `7회`로 바뀝니다.

## 조작 방법

- 맨 위 **난이도 버튼**으로 자릿수를 고릅니다
- **설정(난이도 · 초보 모드 · 무제한 기회)을 바꾸면 그 자리에서 새 판이 시작됩니다.**
  한 판은 처음부터 끝까지 같은 조건이어야 기록이 기록으로서 의미가 있기 때문입니다
- 숫자 버튼을 눌러 자릿수를 채우고 **확인**을 누릅니다
- **이미 고른 숫자를 다시 누르면 빠집니다** (지우기까지 갈 필요 없음)
- **지우기**는 마지막 한 자리를 지웁니다
- **다시하기**는 게임 중에도 언제든 새 판을 시작합니다 (난이도는 그대로 둡니다)
- 예전에 낸 것과 **똑같은 조합**을 넣으면 몇 회에 냈는지 알려주고 확인을 막습니다
  (결과가 뻔한데 시도 횟수만 날아가기 때문입니다. `123`과 `321`은 다른 조합입니다)
- 판이 사라지는 조작(설정 셋 · 다시하기)을 누르면 **확인 창**이 뜹니다.
  단, **한 번이라도 시도한 뒤 아직 끝나지 않은 판일 때만** 묻습니다. 잃을 게 없을 때까지 물으면
  내용을 안 읽고 확인부터 누르는 습관이 들기 때문입니다

## 초보 모드

체크박스로 켜고 끕니다. **기본값은 꺼짐**이고, 켜고 끄면 새 판이 시작됩니다.

켜면 지금까지 알아낸 사실을 **숫자 버튼에 색으로** 보여줍니다. 다음에 무엇을 누를지 판단하는 데 쓰라고 만든 기능입니다.

| 버튼 색 | 뜻 |
|---|---|
| 🔴 빨강 | 자리까지 맞은 숫자 (스트라이크로 확정) |
| 🟡 노랑 | 정답에 있지만 자리가 틀린 숫자 |
| ⬜ 회색 | 정답에 없다고 밝혀진 숫자 |
| 흰색 | 아직 한 번도 써보지 않은 숫자 |

시도 기록에서도 입력한 숫자에 같은 색이 칠해집니다. 스트라이크에는 밑줄이 함께 그어집니다.

## 기술 스택

- Vite + React (JavaScript)
- CSS Modules (`*.module.css`)
- 상태 관리 라이브러리 없이 React 기본 훅만 사용
- 성능 최적화(`useMemo`/`useCallback`) 없음 — 가독성 우선
- `useEffect`는 `ConfirmDialog` 한 곳뿐입니다. 브라우저 `<dialog>`의 `showModal()`을 부르는 용도라
  "React 바깥과 동기화"라는 원래 쓰임에 맞습니다. state에서 계산되는 값은 `useEffect` 없이 그냥 계산합니다

## 실행 방법

```bash
npm install     # 최초 1회
npm run dev     # 개발 서버 실행 (http://localhost:5173)
npm run lint    # 코드 검사
npm run build   # 배포용 빌드
```

## 폴더 구조

```
src/
├─ main.jsx                        React 진입점
├─ App.jsx                         훅에서 받은 값을 화면 조각에 나눠주기만 함
├─ index.css                       전역 스타일 (색·간격 CSS 변수)
├─ constants/
│  └─ gameConstants.js             설정값 (고를 수 있는 자릿수, 최대 시도 10번, 판정 이름)
├─ utils/
│  └─ gameLogic.js                 React와 무관한 순수 함수 (정답 생성, 판정, 힌트)
├─ hooks/
│  └─ useBaseballGame.js           게임 상태 전부 (state, 파생값, 조작 함수)
└─ components/                     화면 조각들 (.jsx와 .module.css를 나란히 배치)
   ├─ DifficultySelector           난이도(자릿수) 버튼 줄
   ├─ GuessInput                   입력 중인 칸 (자릿수만큼)
   ├─ NumberPad                    숫자 버튼 + 지우기/확인
   ├─ SettingToggle                설정 체크박스 (초보 모드·무제한에 두 번 사용)
   ├─ ResultBanner                 게임이 끝났을 때의 결과 메시지
   ├─ HistoryList                  시도 기록 목록
   └─ ConfirmDialog                판이 사라지기 전에 물어보는 확인 창
```

**모든 상태는 `useBaseballGame` 훅이 갖습니다.** `App.jsx`도 자식 컴포넌트도 `useState`를 갖지 않습니다. 값은 아래로(props), 사용자 조작은 위로(콜백) 흐릅니다.

자세한 설계 규칙은 [CLAUDE.md](./CLAUDE.md)에 있습니다.
